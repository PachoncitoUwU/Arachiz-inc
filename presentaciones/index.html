🇺🇸 Abstract · English

Arachiz is an intelligent attendance management system designed for SENA's academic environment. It integrates biometric identification — QR codes, NFC cards, fingerprint sensors, and facial recognition — with a real-time web platform built on React 19 and Node.js. Three user roles with granular permissions. Cloud PostgreSQL via Supabase. Hardware: Arduino Uno + ESP8266 + AS608 + PN532. Live at arachiz.vercel.app.

⚛️ React 19🟢 Node.js 🐘 PostgreSQL🔌 Socket.io ☁️ Supabase📡 ESP8266

Metodología de Desarrollo

Las 6 fases de Arachiz

01
Fase 1
Análisis y Levantamiento

Definición del alcance, estudio de viabilidad del hardware e investigación de metodologías ágiles para entornos educativos del SENA.

02
Fase 2
Diseño Arquitectónico

Mockups en Figma, estructuración del modelo Entidad-Relación y definición del stack tecnológico completo.

03
Fase 3
Implementación IoT

Ensamblaje del Arduino + ESP8266 y programación en C++ para captura de huellas, NFC y comunicación WiFi.

Metodología de Desarrollo

Fases 4, 5 y 6

04
Fase 4
Desarrollo Backend

API RESTful con Node.js, Express y Prisma ORM. Autenticación JWT, WebSockets en tiempo real y endpoints para hardware.

05
Fase 5
Desarrollo Frontend

Interfaces React para administrador, instructor y aprendiz. Reconocimiento facial con face-api.js y NFC móvil.

06
Fase 6
Sincronización y Pruebas

Integración hardware-web, pruebas de estrés, optimización del bundle de 900KB a 209KB y despliegue en Render + Vercel.
