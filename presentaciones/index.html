Control de asistencia inteligente, biometría y gestión eficiente para el SENA

Abstract

El proyecto nace para solucionar el control manual de asistencia en entornos educativos, eliminando el uso de papel y previniendo suplantaciones.

Integramos hardware físico con una plataforma web moderna, ofreciendo respuestas en tiempo real mediante tecnología de vanguardia.

Problema

Llamados a lista lentos, pérdida de tiempo de clase y registros inexactos.

Solución

Sistema automatizado con lectura NFC y biométrica conectada a la nube.

¿Qué es el Sistema?

Es un ecosistema híbrido que permite la validación de identidad en tiempo récord. Consta de dos componentes clave:


Componente Físico (IoT)

Dispositivos instalados en las aulas capaces de leer huellas dactilares y tarjetas de proximidad (NFC).

Componente Lógico (Plataforma Web)

Software administrativo donde los instructores pueden gestionar aprendices, horarios y reportes estadísticos.

Fases del Desarrollo (1 - 3)

Fase 1: Análisis y Levantamiento

Definición del alcance, estudio de viabilidad del hardware e investigación de metodologías.

Fase 2: Diseño Arquitectónico

Creación de mockups en Figma y estructuración del modelo Entidad-Relación de la base de datos.

Fase 3: Implementación IoT

Ensamblaje del Arduino, lectores biométricos y programación en C++ para la captura de datos.

Fases del Desarrollo (4 - 6)

Fase 4: Desarrollo Backend

Construcción de la API RESTful segura con Node.js, Express y Prisma ORM.

Fase 5: Desarrollo Frontend

Desarrollo de las interfaces interactivas para administradores e instructores usando React.

Fase 6: Sincronización y Pruebas

Conexión del hardware web vía Web Serial API, validaciones offline/online y pruebas de estrés.
